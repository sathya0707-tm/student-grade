# 🎓 Student Grade Calculator

A simple web-based Student Grade Calculator built using Python and Flask.

## 🌐 Live Website

👉 https://student-grade-1-c0d9.onrender.com

## ✨ Features

- 👤 Student name input
- 📚 Subject marks input
- ➕ Total marks calculation
- 📊 Average calculation
- 🏆 Automatic grade calculation
- 🌐 Flask web interface
